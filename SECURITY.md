# Security notes

Перед публикацией приложения в интернете:

- создайте `.env` из `.env.example` и задайте длинный случайный `SECRET_KEY`;
- замените `ADMIN_PASSWORD`;
- не коммитьте `.env`, SQLite-базу, прайс-листы и каталог `data/media`;
- включите HTTPS и `SESSION_COOKIE_SECURE=true`;
- заполните реальные данные оператора персональных данных;
- регулярно создавайте резервные копии каталога `data` на production-сервере.

Если секрет когда-либо попал в Git, простого удаления файла из следующего commit недостаточно: считайте секрет скомпрометированным и замените его.
